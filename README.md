# 📋 TaskMaster – Your Personal Task Manager App

**TaskMaster** is a sleek and intuitive Android application that helps you manage your daily tasks, set deadlines, and stay focused. Designed with productivity in mind, it allows users to easily create, update, and delete tasks based on date and time.

---

## 🛠️ Features

- ✅ Create, update, and delete tasks
- 📅 Set task deadlines with date & time pickers
- 📂 Organize tasks by due date
- 🔔 Reminders (optional for future enhancement)
- 🌓 Light & Dark mode support (optional)
- ✨ Beautiful and minimal UI

---
